# SNOWA Cafe admin interface

Static HTML/CSS/JavaScript prototype for the SNOWA Cafe store management interface.

## Preview locally

Open `index.html` in a browser, or serve this folder with a static development server.

## Public preview

Once GitHub Pages is enabled and the deployment workflow finishes, the site will be available at:
https://nguyenhuy141125h.github.io/Asnowa/

This is a visual prototype. Form changes and sample data are not stored on a server.
